# Sandeep M - DevOps Engineer Portfolio

Personal portfolio site built with plain HTML, CSS and JavaScript, hosted on GitHub Pages.

## Files

- `index.html` - page content (about, skills, experience, education, contact)
- `style.css` - styling and responsive layout
- `script.js` - mobile menu and footer year
- `.nojekyll` - tells GitHub Pages to serve files as-is

## Deploy on GitHub Pages

1. Put these files at the root of your repository (for a user site, name the repo `<username>.github.io`).
2. Go to **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Your site will be live at `https://<username>.github.io/` within a minute or two.
