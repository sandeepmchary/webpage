# Sandeep M — DevOps Portfolio

A responsive, static portfolio website built with HTML, CSS, and a small JavaScript file. It is ready to publish with GitHub Pages.

## Files

- `index.html` — portfolio content and page structure
- `styles.css` — responsive styling
- `script.js` — mobile navigation and current footer year

## Publish with GitHub Pages

1. Create or open the GitHub repository you want to use for your portfolio.
2. Upload `index.html`, `styles.css`, `script.js`, and this `README.md` to the repository's **root** folder.
3. Commit the files to your default branch (commonly `main`).
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select your default branch and the `/ (root)` folder, then click **Save**.
7. Wait for the Pages deployment to finish. GitHub will show your site URL in **Settings → Pages**.

For a personal site, a repository named `YOUR-USERNAME.github.io` gives you a URL like `https://YOUR-USERNAME.github.io/`. For another repository, the URL typically includes the repository name.

## Personalize before publishing

- Add your LinkedIn and GitHub profile links in the contact section of `index.html`.
- If you want a downloadable resume, add a PDF named `Sandeep-M-Resume.pdf` to the repository and add a link to it.
- Review the experience descriptions and confirm that every statement accurately reflects your responsibilities before publishing.
- Your email address and phone number are public on this website. Remove or change them if you do not want them publicly visible.

No build process or package installation is required.
